## 被顶下线强制回登录页

- 背景：原 `snowyRequest` 仅在 `code===401` 抛 `SnowyAuthError`，但运行中请求（保存/列表）抛错都被各处 catch 吞掉，不清登录态也不跳登录页；只有启动 `me()` 会清 token。
- 后端事实：sa-token 的 `NotLoginException`（过期/被顶/被踢/未登录）统一返回 code 401，msg 含"顶下线"等字样；官方 `snowy-admin-web/src/utils/codeHandler.js` 用 `RELOGIN_CODES=[401,1011007,1011008]` 拦截后清缓存刷新回登录页。
- `lib/snowy.ts`：定义 `RELOGIN_CODES`；`onAuthExpired(handler)` 订阅机制；`forceRelogin(msg)` 统一处理——`reloginInFlight` 标志合并并发重复触发、`sessionStorage` 写入 `AUTH_EXPIRED_REASON`、`clearSnowyLoginCache()`、通知所有订阅者、抛 `SnowyAuthError`；msg 含顶下线/踢下线/已在其它登录等正则时给出"账号已在其他设备登录，当前会话已被顶下线"专属文案。`snowyRequest` 与 `snowyUpload`(XHR) 都接入。
- `App.tsx`：新增 `resetToLogin`（清 user/modules/permissions/menuTree/externalMenu + forgetModule + go dashboard，不调 logout）；`useEffect(onAuthExpired(resetToLogin))` 注册全局回调；登录后 30s 间隔 `api.me()` 探活，静止页面也能及时发现被顶下线。
- `LoginView.tsx`：挂载时读取并清除 `AUTH_EXPIRED_REASON`，以橙色提示条展示；两个登录入口成功时清空提示。
- 验证：lint/build 通过；浏览器实测——token 失效触发请求→自动回登录页且 token 清空；mock 后端返回 401+msg"token 已被顶下线"→回登录页并显示专属橙色提示条（截图确认）。
