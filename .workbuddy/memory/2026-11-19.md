## 被顶下线强制回登录页

- 背景：原 `snowyRequest` 仅在 `code===401` 抛 `SnowyAuthError`，但运行中请求（保存/列表）抛错都被各处 catch 吞掉，不清登录态也不跳登录页；只有启动 `me()` 会清 token。
- 后端事实：sa-token 的 `NotLoginException`（过期/被顶/被踢/未登录）统一返回 code 401，msg 含"顶下线"等字样；官方 `snowy-admin-web/src/utils/codeHandler.js` 用 `RELOGIN_CODES=[401,1011007,1011008]` 拦截后清缓存刷新回登录页。
- `lib/snowy.ts`：定义 `RELOGIN_CODES`；`onAuthExpired(handler)` 订阅机制；`forceRelogin(msg)` 统一处理——`reloginInFlight` 标志合并并发重复触发、`sessionStorage` 写入 `AUTH_EXPIRED_REASON`、`clearSnowyLoginCache()`、通知所有订阅者、抛 `SnowyAuthError`；msg 含顶下线/踢下线/已在其它登录等正则时给出"账号已在其他设备登录，当前会话已被顶下线"专属文案。`snowyRequest` 与 `snowyUpload`(XHR) 都接入。
- `App.tsx`：新增 `resetToLogin`（清 user/modules/permissions/menuTree/externalMenu + forgetModule + go dashboard，不调 logout）；`useEffect(onAuthExpired(resetToLogin))` 注册全局回调；登录后 30s 间隔 `api.me()` 探活，静止页面也能及时发现被顶下线。
- `LoginView.tsx`：挂载时读取并清除 `AUTH_EXPIRED_REASON`，以橙色提示条展示；两个登录入口成功时清空提示。
- 验证：lint/build 通过；浏览器实测——token 失效触发请求→自动回登录页且 token 清空；mock 后端返回 401+msg"token 已被顶下线"→回登录页并显示专属橙色提示条（截图确认）。

### 编辑器高度适配 + padding 收窄 + 预览开关（后续调整）
- 需求：编辑器高度与容器适配；正文编辑区 padding 太大要收窄；"正文内容"标题右侧加预览开关按钮，默认关闭。
- 高度坑的正解：之前 `height:'100%'` 溢出 54px 是因为 mount div 参与父容器高度计算 + 外层 `overflow-y-auto` 破坏高度传递。正确做法——`ArticlePages` editor 外层 `relative h-full min-h-0`，AiRichEditor 用 `absolute inset-0` + `height:'100%'`（高度由父级决定，不撑高父容器）；`EditorWorkspace` 中间栏内容区在 hasInfo 时用 `p-4 overflow-hidden`（不再 overflow-y-auto）；`index.css` 覆盖 `.article-ai-editor .aieditor{height:100%;border:0;border-radius:0;box-shadow:none}`。实测 mount/aiRoot 均 732px 填满中间栏内容区，两栏/三栏底部都齐平无溢出。
- padding：AiEditor 默认 `.aieditor__prose{padding:64px clamp(28px,9vw,108px) 90px;min-height:520px;font-size:19px}` 过大。`index.css` 覆盖为 `padding:24px 28px 48px;min-height:0;font-size:16px;line-height:1.75`。
- 预览开关：`EditorWorkspace` 加 `showPreview` state（默认 false）+ Eye/EyeOff 按钮（在中间栏 header 右侧）；预览 section 用 `{showPreview && ...}` 包裹；grid 列定义随开关切换（关闭时 hasInfo 两栏、无 info 单栏；打开时恢复三栏/两栏）；按钮文案「打开预览/关闭预览」。视频/图文两栏模式同样可用该开关。
- 验证：lint/build 通过；浏览器实测默认 2 栏（预览隐藏）、点开关变 3 栏且底部齐平、编辑器高度填满、padding 生效。
