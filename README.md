# Domain Stream

Domain Stream 是一个以视频、文章和图文内容为核心的内容展示与管理项目。仓库包含面向用户的内容客户端、内容管理后台、基于 Snowy 的 Java 服务端以及 MySQL 数据库脚本，覆盖内容分类、维护、发布和浏览等常见场景。

## 主要功能

- **内容客户端**：提供视频、文章、图片/图文等内容展示，以及分类浏览和个人中心。
- **内容管理后台**：提供文章、视频、图文等内容管理功能，并包含访客数据看板。
- **服务端**：基于 Snowy 快速开发平台，提供用户、权限等基础能力及内容业务接口。

## 项目结构

| 目录 | 说明 |
| --- | --- |
| `frontend/` | 面向用户的响应式内容客户端，使用 React、TypeScript 和 Vite。 |
| `cms/` | 内容管理工作台，使用 React、TypeScript、Express 和 Vite。 |
| `backend/` | 基于 Java 17、Spring Boot 和 Snowy 的服务端，包含配套的 Vue 管理前端。 |
| `sql/` | MySQL 数据库初始化及业务模块建表脚本。 |

## 核心内容模块

- 通用分类：为文章、视频和图文提供统一的分类能力。
- 文章：管理标题、摘要、正文、作者、来源及发布状态等信息。
- 视频：管理视频地址、封面、时长、简介及播放数据等信息。
- 图文：管理图片列表、图文内容、摘要及发布状态等信息。
